## 01 / About

I build mobile apps that handle real money, real locations and bad networks, and I keep them running after launch.

For the last three years that has meant Flutter in production: ticketing, e-commerce, delivery, ride-hailing and POS. At **Collard** I'm the only Flutter developer, so I own the architecture, the payments, the native bridges and every store release.

I care most about three things: **payment flows that don't fail**, **real-time features that stay in sync**, and **apps that keep working offline**.

Outside the day job I co-run **BitForge**, a two-person dev shop, and I'm building **Alter**, a daily persona-adoption app with real-world missions and a diary.

## 02 / Selected work

### Collard &nbsp;·&nbsp; event ticketing & payments

Sole Flutter developer, end to end. Single and multi-day events, invitations, live seat selection with Seats.io, QR entry scanning, and checkout through two gateways (Paymob with Apple Pay, and Amazon Payment Services). An iOS payment failure was fixed by moving to delegate-driven handling in the native layer. Releases run through GitHub Actions and Fastlane, with Firebase Analytics, Crashlytics and Microsoft Clarity watching stability and usage.

`Clean Architecture` `BLoC / Cubit` `go_router` `Hive` `Seats.io` `Paymob` `Kotlin / Swift channels`
